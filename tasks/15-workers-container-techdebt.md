# Task 15 — Тех. долг: вынос воркеров в отдельный контейнер

|                 |                                                                                                     |
| --------------- | --------------------------------------------------------------------------------------------------- |
| **Приоритет**   | 3 — когда OOM воркера (ts-morph на большой репе) или нагрузка начнёт затрагивать HTTP-сервер        |
| **Зависимости** | Task 14 (архитектура подготовлена: чистая сборка воркеров, in-process state удалён, статус в Redis) |
| **Открывает**   | Горизонтальное масштабирование обработки джоб (N контейнеров воркеров)                              |

## Контекст

Сейчас воркеры живут в одном процессе с HTTP (`initWorkers()` в `main.ts`). Task 14 сделал это безопасным (локи/очереди/статус — в Redis), но сбой воркера (OOM) по-прежнему роняет HTTP-сервер, и масштабировать обработку можно только вместе с вебхук-приёмником.

## Объём работ

- `src/worker.ts`: entrypoint = `initInfrastructure()` + `initWorkers()` без express
- env `WORKER_MODE=embedded|server|worker` (embedded — текущее поведение, дефолт для dev)
- `package.json` scripts: `start:api` / `start:worker` / `start` (embedded)
- `docker-compose.yml`: сервис `worker` из того же образа с другой командой; app остаётся HTTP-only в этом режиме
- Healthcheck воркера: метрика по `worker.isRunning()` / heartbeat-ключ в Redis

## Технические заметки

- Dockerfile не меняется — режим задаётся командой/entrypoint
- Пер-repo Redis-локи (Task 14) гарантируют, что N воркеров не конфликтуют
- Dev-режим (embedded) не меняется — вынос касается только прод-развёртывания

## Критерии приёмки (DoD)

- [ ] `WORKER_MODE=worker` стартует процесс без HTTP-порта (лог: только воркеры)
- [ ] В compose контейнер worker обрабатывает джобы; контейнер app их не обрабатывает (`WORKER_MODE=server`)
- [ ] Два контейнера worker одновременно: джобы одного репо сериуются локом, разных репо — параллельно (лог)
- [ ] `npm run dev` / embedded-режим работают как раньше
- [ ] `lint` + `typecheck` чистые
